❌⭕ Tic-Tac-Toe Game

A fun and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript. Play against a friend and enjoy this classic 3x3 grid game.

🚀 Live Demo

Play the game here:
https://bhagya-priya.github.io/Tic-Tac-Toe/

🧩 Features

🎮 2-player mode: play with a friend on the same device.

🧠 Game logic checks for wins, losses, and ties.

🔄 Reset the board to start a new game.

📱 Fully responsive layout for mobile and desktop.

⚙️ Technologies Used

HTML5 – Game board structure.

CSS3 – Styling, layout, and hover effects.

JavaScript – Game logic and interactivity.

🛠️ How to Play

Open the live demo link.

Player 1 chooses X and Player 2 chooses O.

Players take turns marking a cell on the 3x3 grid.

The first player to get 3 in a row (horizontally, vertically, or diagonally) wins.

Reset the board to start a new game.
